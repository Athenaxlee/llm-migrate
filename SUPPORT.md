# Support

- Use GitHub Discussions for usage questions, migration design, and ideas.
- Use the bug report form for reproducible defects.
- Use the feature request form for scoped product proposals.
- Use the registry update form for model-fact or migration-knowledge changes.
- Use private vulnerability reporting for security issues.

This is a community open-source project. Support is best effort and no response
or resolution time is guaranteed.

When asking for help, share a minimal reproducible example and sanitized command
output. Never post provider credentials, private prompts, customer data, or full
proprietary repositories.
